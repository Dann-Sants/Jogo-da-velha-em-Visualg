# Jogo da Velha em Console (Visualg)

Implementação completa do clássico Jogo da Velha desenvolvida em Portugol utilizando o **Visualg**. O projeto foi criado para praticar lógica de programação, manipulação de matrizes e validação de entradas do usuário.

## Funcionalidades

- **Tabuleiro 3x3 em Matriz:** Exibição dinâmica do tabuleiro atualizado a cada jogada no console.
- **Alternância de Turnos:** Controle automático entre os jogadores (`X` e `O`).
- **Validação de Jogadas:** Impede que o usuário escolha posições fora do intervalo permitido (1 a 9) ou sobrescreva uma casa já ocupada.
- **Verificação de Resultado:** Checagem automática de vitória em linhas, colunas e diagonais, além de detecção de empate ("Deu velha").

## Tecnologias Utilizadas

- **Linguagem:** Portugol
- **Interpretador:** Visualg 3.0
